# Evals

Three suites, versioned in-repo; thresholds gate CI from week 6 (DESIGN §9):

- `redteam/` — attacked-document corpus generated by `redteam/generate.py` from clean seeds × the technique matrix (H1–H6 hiding techniques, D1 directive placements; PDF, HTML and DOCX variants), with a gold manifest. Deterministic and LLM-free, so it runs on every PR. Metrics: precision/recall per technique.
- `zoning/` — labeled documents (30 by week 3, 60 by week 6) spanning assignments, papers, RFPs/specs and web articles. Metrics: macro-F1 per zone, confusion matrix, heuristic-only vs +LLM ablation. PR smoke on 8 docs; the full set runs weekly via the Batches API.
- `conversion/` — golden-file snapshots of converter output for a fixed corpus; catches converter-upgrade regressions cheaply.

Results land in `results/` with a trend table surfaced in the README. Thresholds and cadence: DESIGN §9.
