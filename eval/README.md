# Evals

Two suites gate CI (DESIGN §11):

- `qa/` — grounded-QA cases (YAML: question, fixture corpus, gold requirement checklist, gold evidence spans). Curation starts week 3 (~5/day, ≥ 50 by week 6). Metrics: requirement fulfillment, citation support, verified-citation rate, retrieval recall@20.
- `redteam/` — attacked-document corpus generated by `redteam/generate.py` from clean seeds × technique matrix (hidden text, tiny fonts, off-canvas, metadata, encoding tricks, embedded AI directives). Deterministic, LLM-free, runs fully on every PR. Metrics: precision/recall per technique.

Results land in `results/` with a trend table surfaced in the README. Thresholds and cadence: DESIGN §11.
